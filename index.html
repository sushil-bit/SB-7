How this guide works

🟢 Essential

Strongly recommended for understanding the major characters, rules or story threads that lead into the multiverse crossover.

🟡 Recommended

Useful context that makes later events more meaningful, but you can still follow the main route without it.

⚪ Optional

Extra universe or character material. Great for completionists, but not presented as mandatory.

⚠️ Accuracy note

This is a fan-made guide, not an official Marvel publication. Confirmed release information is prioritized, while future connections are labelled as recommendations rather than facts. Marvel currently lists Avengers: Doomsday for December 18, 2026 and Avengers: Secret Wars for December 17, 2027.

Tip: For a first-ever MCU watch, release order is usually the safest experience. This site is designed primarily as a roadmap, not a replacement for official Marvel/Disney+ chronology.
